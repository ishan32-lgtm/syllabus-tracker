CLASS 9 SYLLABUS TRACKER — INSTALLATION

This is a Progressive Web App (PWA). To install it on Android, it must be hosted over HTTPS.

Easiest free method:
1. On a computer, create a free account at GitHub.
2. Create a new public repository named class9-syllabus-tracker.
3. Upload index.html, manifest.webmanifest, and sw.js from this folder.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Open the generated https://...github.io/... address in Chrome on your Android tablet.
6. Chrome menu (⋮) > Install app or Add to Home screen.

The tracker saves progress in the browser's local storage on that device. Use Export progress occasionally to keep a backup. Do not clear browser site data unless you have exported your progress.
